# 最终报告结构

本文档用于在正式分析前确认最终报告的两份产物如何分工、每部分呈现什么结果、对应什么分析逻辑。具体项目启动后，建议复制为：

```text
reports/final/final_report_structure.md
```

本文件不替代 `docs/analysis_framework.md`，而是把业务分析框架转化为报告结构。

最终报告由同一次 `scripts/generate_final_report.py` 执行生成两份产物：

| 产物 | 路径 | 定位 |
| --- | --- | --- |
| 结论摘要 | `reports/final/final_analysis_report.md` | 只放元数据与运行 ID、核心结论、关键指标、关键图表和交付物索引 |
| 分析详情 | `reports/final/analysis_detail.html` | 放完整分析过程、证据、图表、结果表、口径限制和每节结论 |

结论摘要中的交付物索引必须链接到详情页章节锚点。详情页每个业务问题章节和每个过程章节都必须有本节结论。
