# 需求变更执行记录

本文档记录后续修改如何按预期工作流执行。详细规则见 `docs/09_change_management_standard.md`。

## 使用要求

- 每次受管修改开始前新增一条记录。
- 实施前填写需求、等级、验收标准、影响范围和重跑起点。
- 实施后逐项更新完成情况。
- 存在未完成项或失败项时，状态不能写为“已完成”。
